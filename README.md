# Formulario con validación y cambio de tema

Este proyecto es una pequeña aplicación web de formulario desarrollada con HTML, CSS y JavaScript. Permite completar datos personales, validar la información antes de enviarla y cambiar el estilo visual entre modo claro y oscuro.

## Características

- Formulario con los siguientes campos:
  - Nombre
  - Apellido
  - Correo electrónico
  - Fecha de nacimiento
  - País de residencia
- Validación de campos obligatorios
- Verificación de formato de email
- Validación de fechas dentro de un rango permitido
- Botones para cambiar el tema de la interfaz
- Mensajes de alerta al enviar el formulario

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta `index.html` en tu navegador.

También puedes abrirlo directamente con el navegador desde el sistema de archivos, sin necesidad de un servidor.

## Uso

1. Completa todos los campos del formulario.
2. Haz clic en el botón "¡Enviar!".
3. Si hay errores, el sistema mostrará mensajes indicando qué corregir.
4. Puedes cambiar entre vista clara y oscura con los botones disponibles.

## Notas

El proyecto es una interfaz estática orientada a aprendizaje y validación frontend básica. Si quieres, en el futuro puede ampliarse con:

- almacenamiento en base de datos
- estilos más avanzados
- diseño responsivo
- validación más robusta con mensajes visuales en el formulario
